# DigiVentures (دیجی‌ونچرز)

> پلتفرم جامع سرمایه‌گذاری جسورانه شرکتی (CVC) گروه دیجی‌کالا مبتنی بر **Next.js 14 (App Router) + TypeScript + Tailwind CSS + PostgreSQL + Drizzle ORM**.

---

## ۱. ویژگی‌ها و قابلیت‌های کلیدی

- **طراحی و هویت بصری:** بازآفرینی استانداردهای بصری مدرن M12، فونت‌های یکان‌بخ (Yekan Bakh) و گیلروی (Gilroy)، رنگ سبز سازمانی (`#00B140`)، جهت‌گیری پیش‌فرض راست‌به‌چپ (RTL)، کارت‌های سه‌بعدی تعاملی (3D Flip Cards)، مارکی پیوسته و انیمیشن‌های لاتی.
- **پورتال جذب و ارزیابی استارتاپ‌ها:**
  - فرم ۳ مرحله‌ای ثبت درخواست سرمایه‌گذاری با اعتبارسنجی سروری Zod
  - آپلود و پردازش امن فایل ارزیابی (Pitch Deck تا ۲۰ مگابایت) با بررسی امضای باینری (Magic Bytes) برای PDF، PPT و PPTX
  - چرخه حیات و ماشین وضعیت دقیق: `draft` ➔ `submitted` ➔ `under_review` ➔ `needs_revision` / `accepted` / `rejected`
  - قفل همروندی خوش‌بینانه (`version`) جهت جلوگیری از تعارض تغییرات همزمان مدیران
  - داشبورد پیگیری کارآفرین و امکان اصلاح و ارسال مجدد طرح‌ها
- **پیشخوان مدیریت و ارزیابی تخصصی (Admin Back-Office):**
  - صف ارزیابی پرونده‌ها با فیلتر وضعیت و جست‌وجوی بلادرنگ
  - فرم ثبت یادداشت‌های محرمانه تیم سرمایه‌گذاری (مخفی از کارآفرین)
  - مدیریت نقش‌ها و سطوح دسترسی کاربران (`customer`، `admin`، `super_admin`)
  - ویرایشگر متون و قالب‌های ایمیل سیستم با پیش‌نمایش زنده
- **اتاق خبر و وبلاگ تحریریه (News CMS):**
  - پنل ایجاد، ویرایش و انتشار مقالات با تولید خودکار اسلاگ و زمان مطالعه
  - متادیتای ساختاریافته سئو (Schema.org `NewsArticle` JSON-LD) و اشتراک‌گذاری
- **ارتباطات تراکنشی (Transactional Email):**
  - ارسال ایمیل‌های واکنش‌گرای راست‌به‌چپ با Nodemailer
  - استفاده از الگوی Transactional Outbox جهت تضمین پایداری و ارسال غیرهمگام
- **امنیت سخت‌گیرانه:**
  - هش گذرواژه‌ها با الگوریتم مدرن **Argon2id**
  - نشست‌های مبتنی بر توکن‌های تصادفی رمزنگاری‌شده در دیتابیس با کوکی‌های امن `HttpOnly`
  - هدرهای امنیتی سخت‌گیرانه (HSTS, CSP, X-Frame-Options, X-Content-Type-Options)
  - مقابله قاطع با آسیب‌پذیری‌های IDOR، CSRF، Brute-force و Path Traversal

## ۲. ساختار پروژه

```text
├── app/                  # صفحات و مسیرهای Next.js 14 App Router
│   ├── (public)/         # صفحات عمومی (صفحه اصلی، درباره ما، پورتفولیو، تیم، اخبار، تماس)
│   ├── (auth)/           # احراز هویت (ورود، ثبت‌نام، فراموشی و بازنشانی گذرواژه)
│   ├── (portal)/         # پورتال متقاضیان (ثبت درخواست، پیگیری درخواست‌ها)
│   ├── (admin)/          # پیشخوان مدیریت (بررسی طرح‌ها، مدیریت کاربران، اخبار، قالب‌های ایمیل)
│   ├── api/              # مسیرهای API احراز هویت، پرونده‌ها، اخبار و تماس
│   ├── sitemap.ts        # نقشه سایت پویا (Dynamic Sitemap)
│   └── robots.ts         # سیاست‌های دسترسی خزنده‌ها
├── components/           # کامپوننت‌های ماژولار React
├── modules/              # سرویس‌ها و منطق کسب‌وکار دامنه‌ها (Auth, Requests, Storage, News, Email)
├── db/                   # پایگاه داده PostgreSQL (Drizzle ORM، اسکیما، مایگریشن و سید)
├── actions/              # سرور اکشن‌های تراکنشی
├── lib/                  # ابزارها، لاگر ساخت‌یافته، مدیریت خطاها، تنظیمات محیطی و ایمیل
├── public/               # دارایی‌های ایستا (فونت‌ها، لوگوها، تصاویر، وکتورها)
├── storage/              # محل ذخیره‌سازی محلی فایل‌های بارگذاری‌شده خارج از وب‌روت
├── scripts/              # اسکریپت‌های سیستمی (پشتیبان‌گیری دیتابیس، ورکر ایمیل، راستی‌آزمایی)
├── deploy/               # پیکربندی استقرار روی لینوکس (Nginx, Systemd, PM2)
└── tests/                # تست‌های خودکار واحد و یکپارچگی (Vitest)
```

## ۳. پیش‌نیازها و راه‌اندازی محلی

### پیش‌نیازها
- **Node.js:** نسخه ۲۰ به بالا
- **PostgreSQL:** نسخه ۱۵ به بالا
- **مدیر بسته:** `pnpm` یا `npm`

### مراحل راه‌اندازی

۱. **نصب وابستگی‌ها:**
   ```bash
   npm install
   ```

۲. **تنظیم متغیرهای محیطی:**
   یک نسخه از فایل `.env.example` را به نام `.env.local` ایجاد کرده و اطلاعات اتصال دیتابیس و ایمیل را وارد کنید:
   ```bash
   cp .env.example .env.local
   ```

۳. **ایجاد پایگاه داده و بارگذاری داده‌های اولیه:**
   ```bash
   npm run db:migrate
   npm run db:seed
   ```

۴. **اجرای سرور توسعه:**
   ```bash
   npm run dev
   ```
   برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

## ۴. دستورات خط فرمان (Scripts)

| دستور | توضیحات |
|---|---|
| `npm run dev` | اجرای برنامه در محیط توسعه با HMR |
| `npm run build` | ساخت بهینه‌سازی‌شده برای محیط عملیاتی (Production Build) |
| `npm run start` | اجرای سرور پروداکشن |
| `npm run typecheck` | بررسی سلامت تایپ‌ها با کامپایلر تایپ‌اسکریپت (`tsc --noEmit`) |
| `npm test` | اجرای تمامی آزمون‌های خودکار با Vitest |
| `npm run db:migrate` | اجرای مایگریشن‌های پایگاه داده PostgreSQL |
| `npm run db:seed` | بارگذاری کاربران اولیه، مقالات و قالب‌های ایمیل |
| `npm run outbox:process` | اجرای ورکر پردازش صف ایمیل‌های تراکنشی |
| `npm run backup` | تهیه نسخه پشتیبان از دیتابیس و فایل‌های پیچ‌دک |
