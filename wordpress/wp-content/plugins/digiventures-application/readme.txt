Secure frontend investment-request workflow and complete reference-site presentation for DigiVentures. Install the Hello Elementor parent theme and the DigiVentures Hello Child theme, activate this plugin, then open DigiVentures > Setup.

== Security ==
Request changes require a WordPress REST nonce, authenticated capability and server-side ownership/state checks. Registration creates customers only. Pitch decks accept PDF/PPT/PPTX up to 20 MiB.

== Installation ==
1. Upload this ZIP through Plugins > Add New > Upload Plugin.
2. Install Hello Elementor and activate the DigiVentures Hello Child theme.
3. Activate this plugin and open DigiVentures > Setup as a WordPress administrator.
4. Configure SMTP and test contact plus acceptance/rejection emails.

== Uninstall ==
Data is retained by default. Set option `dv_delete_data_on_uninstall` to `1` only after taking a backup if permanent deletion is required.
