# Deployment summary

Install Hello Elementor first, then upload and activate `release/digiventures-hello-child.zip` through Appearance → Themes. Upload `release/digiventures-application.zip` through Plugins and choose **Replace current with uploaded** when upgrading from 1.0. Activate it and run **DigiVentures → Setup**. Setup repairs v1 placeholders, sets the static homepage, and refreshes permalinks. See `CPANEL_DEPLOYMENT.md` for the full runbook.
