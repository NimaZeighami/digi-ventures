# Frontend inventory

The Vite/Tailwind reference has ten RTL Persian HTML pages, `src/styles.css`, `src/main.js`, Yekan Bakh and Gilroy fonts, logo images, and 19 startup portfolio images. Design tokens: green `#00B140`, dark `#10171F`, dark section `#18212B`, light `#F7F7F7`, text `#101413`, muted `#6B7280`; desktop container max-width is 1280px; principal responsive breakpoints are 640px, 1024px and 1280px. Components repeat a dark fixed header, responsive mobile menu, footer, rounded cards, green CTAs, dark patterned heroes, reveal animation, sliders, input focus styles, alerts and auth shell.

`src/main.js` supplies mobile navigation, reduced-motion-aware reveal/counters/sliders, client upload hinting, and static API form wiring. Its validation is UX-only; the plugin replaces all sensitive behavior server-side.
