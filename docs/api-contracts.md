# REST contracts

Namespace: `digiventures/v1`. REST routes use cookie authentication and `X-WP-Nonce` generated by `wp_create_nonce('wp_rest')`.

| Route | Method | Permission | Result |
|---|---|---|---|
| `/auth/login` | POST | public, rate-limited | sets WordPress auth cookie / redirect URL |
| `/auth/register` | POST | public, rate-limited | customer account / redirect URL |
| `/auth/lost-password` | POST | public, rate-limited | generic success response |
| `/contact` | POST | public nonce, honeypot, rate-limited | sends sanitized message to configured recipient |
| `/requests` | POST | `create_request` | request ID/status |
| `/requests/{id}` | GET | owner or reviewer | sanitized request |
| `/requests/{id}` | POST (multipart-safe) | owner editable state | request ID/status |
| `/requests/{id}/status` | POST | `change_request_status` | updated status |
| `/requests/{id}/download` | GET | owner or reviewer | authorized file redirect |
| `/users/{id}/role` | POST | `manage_application_users` | new role |

Errors follow WordPress REST shape with a stable code, translated message and HTTP 400/401/403/404/409/429 as appropriate.
