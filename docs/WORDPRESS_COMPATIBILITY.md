# راهنمای جامع سازگاری، توسعه و اکوسیستم افزونه‌های وردپرس
# DigiVentures WordPress Compatibility, Plugins & Extensibility Guide

این سند برای تیم‌های توسعه، مدیران فنی و توسعه‌دهندگان وردپرس تهیه شده است تا سازگاری کامل پلتفرم دیجی‌ونچرز با هسته وردپرس (WordPress Core)، سایر افزونه‌ها (Plugins)، امکان ایجاد صفحات جدید، توسعه سفارشی و استفاده از هوک‌ها (Hooks & Filters) را شرح دهد.

---

## ۱. پاسخ به نیاز توسعه: آیا تمام امکانات وردپرس فعال و در دسترس هستند؟

**بله، ۱۰۰٪.**
پلتفرم دیجی‌ونچرز بر پایه استانداردهای رسمی وردپرس (WordPress Coding Standards & Public APIs) ساخته شده است:
- هیچ تغییری در هسته وردپرس (Core) داده نشده است.
- جداول پایگاه داده و متادیتاها با پیشوند استاندارد `$wpdb->prefix` و کوئری‌های آماده (`$wpdb->prepare`) مدیریت می‌شوند.
- سیستم کاربران از جدول استاندارد `wp_users` و APIهای رسمی هش و نشست وردپرس (`wp_signon`, `wp_set_auth_cookie`, `wp_logout`, `wp_lostpassword_url`) استفاده می‌کند.
- تمام ویژگی‌های پیشخوان وردپرس (Gutenberg Blocks، Classic Editor، Menus، Media Library، Widgets، Customizer، CPTs و REST API) فعال و بدون اختلال هستند.

---

## ۲. قالب‌های برگه در پوسته فرزند (`digiventures-hello-child`)

هنگام ساخت یک برگه یا نوشته جدید در وردپرس (`Pages -> Add New` یا `Posts -> Add New`)، مدیر یا توسعه‌دهنده به قالب‌های زیر دسترسی دارد:

| قالب برگه | نام در ویژگی‌های برگه | کاربرد |
|---|---|---|
| **DigiVentures Canvas** | `dv-canvas.php` | صفحه خالی و بدون هدر/فوتر برای لندینگ‌پیج‌ها، صفحات تمام‌عرض یا صفحاتی که خودشان ساختار کامل دارند. |
| **DigiVentures Standard Page** | `dv-page.php` | **قالب استاندارد و پیشرفته دیجی‌ونچرز**؛ هدر کامل سایت، منوی ریسپانسیو موبایل و دسکتاپ، کانتینر تایپوگرافی فارسی برای محتوای متنی/بلوک‌های گوتنبرگ، و فوتر رسمی سایت را رندر می‌کند. |
| **Default Template** | پوسته مادر (`hello-elementor`) | قالب پیش‌فرض والد برای صفحات عادی یا زمانی که صفحه‌ساز المنتور هدر/فوتر اختصاصی خود را اعمال می‌کند. |

### نمونه استفاده برای صفحات جدید (مانند قوانین، حریم خصوصی، درباره ما ۲، سوالات متداول):
1. در پیشخوان وردپرس به بخش **برگه‌ها -> افزودن جدید** بروید.
2. متن، تصاویر، جداول یا فرم‌های خود را در ویرایشگر گوتنبرگ وارد کنید.
3. در سایدبار سمت چپ (ویژگی‌های برگه / Page Attributes)، قالب را روی **DigiVentures Standard Page** قرار دهید.
4. برگه را منتشر کنید؛ برگه با هدر، استایل‌های برند، فونت وزیرمتن/یکان‌بخ و فوتر دیجی‌ونچرز نمایش داده می‌شود.

## ۳. شورت‌کدهای مستقل برای توسعه‌دهندگان

توسعه‌دهندگان می‌توانند از شورت‌کدهای زیر در هر برگه، نوشته، ابزارک متنی، یا قالب المنتور استفاده کنند:

| شورت‌کد | عملکرد |
|---|---|
| `[dv_header]` | خروجی هدر کامل دیجی‌ونچرز با منوی اصلی، ورود/حساب کاربری و منوی موبایل |
| `[dv_footer]` | خروجی فوتر کامل دیجی‌ونچرز با لینک‌های اکوسیستم، شبکه‌های اجتماعی و کپی‌رایت |
| `[dv_contact_form]` | فرم امن تماس با دیجی‌ونچرز با اعتبارسنجی ایجکس، هانی‌پات ضد اسپم و ارسال ایمیل |
| `[dv_request_form]` | فرم ثبت یا ویرایش درخواست سرمایه‌گذاری بنیان‌گذاران با آپلود Pitch Deck |
| `[dv_customer_dashboard]` | داشبورد پیگیری و مدیریت درخواست‌های سرمایه‌گذاری برای مشتریان |
| `[dv_request_management]` | پنل بررسی، تغییر وضعیت و یادداشت‌گذاری درخواست‌ها برای مدیران بررسی |
| `[dv_request_user_management]` | پنل مدیریت نقش کاربران و ترفیع/تنزل سطح دسترسی |
| `[dv_email_management]` | پنل ویرایش متون و قالب‌های ایمیل‌های ارسالی سیستم |
| `[dv_login]` / `[dv_register]` | فرم‌های فرانت‌اند ورود و ثبت‌نام با پاپ‌آپ و مدیریت نشست |
| `[dv_reference_page page="home"]` | رندر صفحات ارجاع دیجی‌ونچرز (`home`, `about`, `portfolio`, `team`, `news`, `contact`) |

## ۴. ماتریس سازگاری با افزونه‌های محبوب وردپرس

| دسته‌بندی افزونه | نمونه‌های تست‌شده و سازگار | نحوه عملکرد و هماهنگی |
|---|---|---|
| **سئو (SEO)** | Rank Math, Yoast SEO, SEOPress, All-in-One SEO | به محض فعال‌سازی، سیستم بومی تگ‌های خود را غیرفعال کرده و کنترل کامل تگ‌های متا، کلمات کلیدی، اسکیما و سوشال‌کارت‌ها را به افزونه سئو واگذار می‌کند. چکیده صفحات (Excerpt) از پیش آماده شده تا پیش‌نمایش گوگل فوراً پر شود. |
| **فرم‌سازها** | Contact Form 7, WPForms, Gravity Forms, Formidable | شورت‌کدهای فرم‌سازها در تمام صفحات و در قالب `dv-page.php` با استایل‌های ری‌اسپانسیو اجرا می‌شوند. |
| **کش و افزایش سرعت** | LiteSpeed Cache, WP Rocket, W3 Total Cache, Redis Object Cache | کوکی‌های نشست استاندارد وردپرس رعایت شده، نانس‌های امنیتی در هدر ریکوئست‌های REST ارسال می‌شوند و استایل‌ها با شناسه نسخه (`DV_APP_VERSION`) لود می‌شوند. |
| **امنیت و فایروال** | Wordfence, iThemes Security, Sucuri, Cloudflare | ریت‌لیمیتینگ داخلی، احراز هویت با Nonce، اعتبارسنجی فایل‌های آپلودی بر اساس MIME و پسوند (حداکثر ۲۰ مگابایت)، و کوئری‌های امن با `$wpdb->prepare`. |
| **ارسال ایمیل (SMTP)** | WP Mail SMTP, FluentSMTP, Post SMTP | پلاگین از تابع استاندارد `wp_mail()` وردپرس استفاده می‌کند؛ بنابراین هر سرویس SMTP یا وب‌هوک ایمیلی بدون تغییر کد کار می‌کند. |
| **چندزبانه (Multilingual)** | Polylang, WPML | توابع جابه‌جایی آدرس (`Roles::page_url`) با فیلترهای استاندارد `get_permalink()` هماهنگ هستند و با ترجمه برگه، آدرس‌های زبان جدید خودکار جایگزین می‌شوند. |
| **فیلدهای سفارشی و CPT** | Advanced Custom Fields (ACF), Pods, Custom Post Type UI | فیلدهای اختصاصی و پست‌تایپ‌های جدید به راحتی در برگه‌های استاندارد یا با هوک‌های وردپرس قابل استفاده هستند. |
| **فروشگاه و عضویت** | WooCommerce, MemberPress | قالب فرزند پشتیبانی رسمی `add_theme_support('woocommerce')` را داراست. |

## ۵. فیلترها و هوک‌های اختصاصی برای توسعه‌دهندگان (Developer Hooks)

توسعه‌دهندگان در کد قالب یا افزونه‌های دیگر می‌توانند با هوک‌های زیر رفتار دیجی‌ونچرز را کنترل کنند:

### ۱. لود اجباری استایل‌ها و اسکریپت‌های دیجی‌ونچرز:
```php
// فعال یا غیرفعال کردن استایل‌ها/اسکریپت‌های دیجی‌ونچرز در مسیرهای سفارشی
add_filter( 'dv_enqueue_application_assets', function( $should_enqueue ) {
    if ( is_page( 'my-custom-landing' ) ) {
        return true;
    }
    return $should_enqueue;
} );
```

### ۲. اعطای دسترسی به پیشخوان مدیریت وردپرس (wp-admin):
به صورت پیش‌فرض مشتریان از ورود به پیشخوان وردپرس منع می‌شوند. اگر افزونه دیگری نقشی مانند «نویسنده»، «مدیر فروشگاه» یا «ویراستار» اضافه کرد:
```php
add_filter( 'dv_allow_wp_admin_access', function( $allowed, $user ) {
    if ( in_array( 'editor', (array) $user->roles, true ) || in_array( 'shop_manager', (array) $user->roles, true ) ) {
        return true; // دسترسی به wp-admin آزاد می‌شود
    }
    return $allowed;
}, 10, 2 );
```

### ۳. نمایش یا پنهان‌سازی نوار ابزار بالای وردپرس (Admin Bar):
```php
add_filter( 'dv_show_admin_bar', function( $show, $user ) {
    return current_user_can( 'edit_posts' );
}, 10, 2 );
```

### ۴. دسترسی اضطراری به صفحه پیش‌فرض لاگین وردپرس:
اگر در شرایط خاص نیاز داشتید مستقیماً وارد فرم پیش‌فرض وردپرس (`/wp-login.php`) شوید:
کافی است پارامتر `?dv_admin=1` را به آدرس اضافه کنید:
`https://yourdomain.com/wp-login.php?dv_admin=1`
این کار ریدایرکت خودکار به صفحه `/login/` را موقتاً غیرفعال می‌کند.
