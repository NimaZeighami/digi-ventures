# Elementor strategy

Elementor Free and Hello Elementor form the requested editing stack. The DigiVentures Hello Child theme supplies the Canvas template. The plugin registers Request Form, Customer Dashboard, Request Management, User Management, Login, Logout, Register and Password Recovery views through a public Elementor widget API. No control exposes a status rule, user ID, permission or API secret.

Setup creates complete reference-backed pages and secure dynamic shortcodes, so exact production rendering does not depend on Elementor's private document schema. Every page opens in Elementor and the dynamic widget is recognized. No guessed template JSON is packaged.
